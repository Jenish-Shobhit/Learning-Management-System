# Code of conduct

Be respectful and constructive in issues, pull requests, and discussions. Harassment, discriminatory language, personal attacks, and sharing another person's private information are not acceptable.

Project maintainers may edit, hide, or remove contributions that violate these expectations. To report a conduct concern, contact the repository owner through a private channel listed on their GitHub profile when available. If no private channel is available, use GitHub's report-content feature. Avoid posting private details publicly.
