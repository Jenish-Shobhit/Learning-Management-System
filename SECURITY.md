# Security policy

This is an educational prototype. The current Spring Security configuration permits every API request, and the login response does not establish an authenticated session. Do not deploy it with real accounts or sensitive data without first implementing and reviewing access control and account recovery.

Private vulnerability reporting is currently disabled. If you find a vulnerability, open an issue asking for a private reporting channel **without including the vulnerability details**. Do not post exploit details or credentials publicly.

There is no published support or response-time guarantee.
